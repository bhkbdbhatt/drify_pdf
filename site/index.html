Key Features

Built for LLM evaluation, benchmarking, and reliability testing

🔁

Multi-run Evaluation

Run the same extraction N times with configurable runs and rate limiting.

📊

Per-field Drift Analysis

Numeric variance, string edit distance, date ranges, and array consistency scoring.

🔍

Drift Diagnosis

Split variance into parsing vs sampling components to pinpoint the root cause.

⚡

Live Progress

Real-time WebSocket updates as runs complete with detailed status tracking.

🆚

Task Comparison

Side-by-side comparison of different tasks/models with automated verdicts.

🧾

Raw Run Inspection

View each LLM response and parsed JSON to debug inconsistencies.

How it works

From PDF to drift report in minutes

1

Upload PDF & Define Schema

Provide your PDF and extraction prompt/schema. Choose blackbox (extract from raw text) or parsed mode.

2

Run Multiple Times

Send to your chosen model (OpenAI/Anthropic) N times with rate limiting.

3

Analyze & Diagnose

Get per-field drift metrics, consistency scores, and diagnosis of variance sources.
